# Melyo — редизайн, JSX-пакет

Экраны приложения в новой айдентике, готовые к переносу на сайт: чистый React + инлайн-стили,
без CSS-фреймворков и внешних зависимостей (кроме шрифта Montserrat).

## Файлы

| Файл | Что внутри |
| --- | --- |
| `theme.js` | Брендовые токены: цвета, шрифт, радиусы. Начинайте отсюда. |
| `MelyoMobileScreens.jsx` | 11 мобильных экранов: велком, разминка, колода дилемм, результат, шаринг, путь обучения, урок, квиз, домашка, пейволл, метрики. |
| `MelyoDesktopScreens.jsx` | 6 десктопных экранов: урок (сайдбар + заметки), путь обучения, колода дилемм, результат диагноза, квиз, метрики. |
| `PhoneFrame.jsx` / `BrowserFrame.jsx` | Только оболочки для показа макета. **На проде не нужны** — берите содержимое внутри них. |
| `style-utils.js` | `s()` — парсер CSS-строки в объект стилей. Нужен там, где стиль зависит от состояния (карточки книг, точки прогресса, столбцы графика). |
| `assets/` | Маскот-хамелеон (4 позы) и брендовые пятна, вырезанные из брендбука, PNG с прозрачностью. |

## Подключение

```jsx
import MelyoMobileScreens from './jsx/MelyoMobileScreens';
import MelyoDesktopScreens from './jsx/MelyoDesktopScreens';
```

В `<head>` (или в глобальный CSS) добавьте шрифт:

```html
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Montserrat:ital,wght@0,300;0,400;0,500;0,600;0,700;0,800;0,900;1,300;1,500&display=swap" rel="stylesheet">
```

Пути к картинкам в разметке — `assets/…`. Перенесите папку `assets/` в `public/` (или замените
на свои импорты бандлера).

## Как разбирать на страницы

Оба файла — одно полотно с подписанными экранами. Чтобы вытащить экран:

1. Найдите комментарий-заголовок (например `{/* 7 · Микро-урок */}`).
2. Возьмите JSX **внутри** `<PhoneFrame>` / `<BrowserFrame>` — это и есть страница.
3. Данные экрана возьмите из `useMobileData()` / `useDesktopData()` и замените на реальные.

## Правила айдентики

- Заголовки — Montserrat 900, UPPERCASE, `letter-spacing: -0.01em`; текст — 500.
- Кнопки — пилюли (`borderRadius: 999`); главная — заливка `#01D27F`, текст `#014753`.
- Плашки: мятная `#D2FFB4` (успех, акцент), лавандовая `#C5B6F2` (данные, второстепенное),
  тёмная `#014753` (инверсия, шаринг).
- Границы — `1.5px solid #E7E4F3`, активное состояние — `2px solid #01D27F`.
- Маскот-хамелеон — компаньон: реплика в «пузыре» рядом, не декор ради декора.
- Лайм `#C6F220` — только точечно (номера шагов, бейджи).
